# davidtucker/scoop-bucket

[Scoop](https://scoop.sh) bucket for [envhaul](https://github.com/davidtucker/envhaul), a CLI that hauls config and secrets from AWS into `.env` files.

## Install

```powershell
scoop bucket add davidtucker https://github.com/davidtucker/scoop-bucket
scoop install envhaul
```

Upgrade with `scoop update envhaul`.

## About this repository

The manifests here are generated by envhaul's release pipeline ([GoReleaser](https://goreleaser.com)) on every stable release. Please don't edit them by hand; changes are overwritten by the next release.

Report problems in the [envhaul repository](https://github.com/davidtucker/envhaul/issues). Every release is signed and has build provenance; see [verifying releases](https://davidtucker.github.io/envhaul/security/#verifying-releases).
